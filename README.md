# 乐谱反复段展开工具

供排练使用的 Web 应用：逐行输入小节编号与反复记号，自动校验并展开为实际演奏顺序，
页面展示演奏序号、原小节编号、源行号和每次演奏的起止时间（毫秒），并可下载同内容的 CSV；
还支持按起止毫秒查询时间窗内的节拍点（时间、演奏序号、原小节编号、拍序、首拍标记）。
可另附多行“演奏序号=BPM”的临时变速方案，展开与节拍点查询共用同一速度轨迹。

## 启动

一条命令完成构建并启动：

```bash
docker compose up --build
```

容器启动时会自动安装依赖（`pip install -r requirements.txt`）并启动应用。

## 访问

- 网页：浏览器打开 <http://localhost:5000>
- API：同样经由 5000 端口访问
  - `POST http://localhost:5000/api/expand`，请求体 `{"input": "小节编号逐行文本", "tempo": "可选的临时变速方案"}`
  - `POST http://localhost:5000/api/beats`，请求体 `{"input": "...", "start_ms": 0, "end_ms": 1000, "tempo": "可选的临时变速方案"}`

`tempo` 为可选字段：多行文本，每行一条 `演奏序号=BPM`（见下文“临时变速方案”）；
省略或留空时按原谱速度计算。

## 配置

| 环境变量 | 默认值 | 说明 |
| -------- | ------ | ---- |
| `PORT`   | `5000` | 应用监听端口（修改后请同步调整 compose 的端口映射） |

## 输入格式

每行一个小节编号：

- 编号前加 `|:` 表示反复起点
- 编号后加 `:|xN` 表示反复终点，`N` 为重复次数（2~9）
- 反复段允许嵌套；空行会被忽略
- 行末可附时间标记 `[拍数@BPM]` 或 `[拍数]`：
  - 只写 `[拍数]` 时不切换速度；完全不写标记时拍数默认为 4
  - 带速度的小节在每次演奏到时先切换速度，再累计时长
  - 未标速度的小节沿用上一演奏小节的速度，初始速度为 120 BPM
  - 拍数与 BPM 必须为正整数

示例：

```
1[4@120]
2
|:3
4[2]
|:5
6:|x3
7:|x2[4@90]
8
```

展开结果：`1 2 3 4 5 6 5 6 5 6 7 3 4 5 6 5 6 5 6 7 8`（共 21 小节）。

## 排练时间轴

每个演奏到的小节按 `拍数 × 60 / BPM` 秒累计时长，时间轴从 0 开始；
结果中每个小节的起止时间单位为毫秒，累计时保留完整精度，输出时四舍五入到最近毫秒。
上例前 10 个演奏小节为 120 BPM，第 11 个（小节 7）起切换为 90 BPM，总时长 47000 毫秒。

## 临时变速方案

在小节输入下方的“临时变速”框中，每行填写一条 `演奏序号=BPM`，
展开与节拍点查询共用该方案（即同一速度轨迹）：

- 演奏序号按反复展开后的实际轮次计数（从 1 开始），BPM 为正整数
- 演奏到指定轮次时，临时速度优先于该小节的原谱速度，并继续传给后续未标速小节
- 遇到下一处原谱显式速度或下一条临时变速时重新切换
- 空行会被忽略；序号重复、超出展开范围或格式错误时，
  返回的错误会标注“临时变速”及方案内的行号

例如对上例使用方案：

```
11=100
16=60
```

则第 11 轮（小节 7）临时切换为 100 BPM（覆盖原谱的 90 BPM），
第 16 轮（小节 5）起再切换为 60 BPM；第 20 轮再次演奏到小节 7 时，
遇原谱显式速度 90 BPM 重新切换并沿用至曲终，总时长 51133 毫秒。

## 节拍点查询

在展开结果下方输入起止毫秒，即可列出时间窗内的每个拍点：
时间（毫秒）、演奏序号、原小节编号、拍序与首拍标记。

- 时间窗按左闭右开 `[起始, 结束)` 处理
- 落窗判断使用未取整的累计时间，展示毫秒仍四舍五入到最近毫秒
- 反复回跳后，未标 BPM 的小节沿用上一实际演奏小节的速度
- 查询按小节跨度跳过窗外拍点；窗内拍点超过 5000 时停止并指出对应源行

## 校验规则

- 格式错误：定位到具体输入行
- 拍数与 BPM 必须为正整数，错误定位到源行
- 小节编号必须唯一，重复时指出首次出现的行号
- `|:` 与 `:|xN` 必须配对，未配对时定位到对应行
- 展开超过 5000 小节时停止，并指出导致超限的源行
- 节拍点查询的起止毫秒必须为数字，起始不为负且结束大于起始；
  时间窗内拍点超过 5000 时停止，并指出对应源行
- 临时变速方案的演奏序号与 BPM 必须为正整数；序号重复时指出方案内首次出现的行号，
  序号超出展开范围时指出展开后的总小节数；方案错误统一标注“临时变速”及方案内行号

## 本地开发（不使用 Docker）

```bash
pip install -r requirements.txt
python app.py
```

## 项目结构

```
app.py               Flask 应用与 API
repeats.py           反复段解析、校验、展开、排练时间轴与节拍点查询

requirements.txt     Python 依赖
Dockerfile           镜像构建（依赖随容器启动安装）
docker-compose.yml   Compose 编排
```
